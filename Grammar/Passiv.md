# Passiv

## Vorgangspassiv

Handlung, Vorgang, dynamische Bewegung: "Was passiert?"

### Bildung

- *werden* (+ von `D`) + Partizip II
  - Präsens: ***werden*** + Partizip II
  - Präteritum: ***wurden*** + Partizip II
  - **Perfekt**: ***sein*** + Partizip II + **worden**
  - Modalverb: ***müssen*** + Partizip II + **werden**
  - (Optional) Plusquamperfekt: ***waren*** + Partizip II + **worden**
  - (Optional) Futur I: ***werden*** + Partizip II + **werden**
  - (Optional) Futur II: ***werden*** + Partizip II + **worden** + **sein**

### Beispiele

- Das Fahrrad wird abgeschlossen.

- Er wird verletzt.

- Der Kuchen wird (vom Bäcker) gebacken.

- Der Kuchen muss gebacken werden.

- Die Frau wurde angefahren.

- Ein Verband wurde der Frau angelegt.

- Die Frau wird ins Krankenhaus gebracht.

### Vom Aktiv zum Passiv

- S<sub>N</sub> + *V* + O<sub>A</sub>. =
- O<sub>N</sub> + *werden* + (von + S<sub>D</sub>) + V<sub>Partizip II</sub>.

#### Beispiele

- Der Mann öffnet das Fenster. = Das Fenster wird (vom Mann) geöffnet.
- Die Frau liest das Buch = Das Buch wird (von der Frau) gelesen.

### Verben ohne Passiv

- Verben mit Hilfeverb "sein"
  - gehen
  - aufstehen
- Echte Reflexive Verben
  - konzentrieren
- Verben mit keine Handlung
  - besitzen
  - haben
  - wissen
  - kennen

## Zustandspassiv

Ergebnis, bewegungsloser Zustand: "Wie ist der Zustand?"

### Bildung

- *sein* + Partizip II
  - Präsens: ***sein*** + Partizip II
  - Präteritum: ***waren*** + Partizip II
  - Perfekt: ***sein*** + Partizip II + **gewesen**
  - (Optional) Plusquamperfekt: ***waren*** + Partizip II + **gewesen**
  - (Optional) Futur: ***werden*** + Partizip II + **sein**

### Beispiele

- Das Fahrrad ist abgeschlossen.
- Er ist verletzt.

### Vom Zustandspassiv zum Adjektiv

- V<sub>Partizip II</sub> ≈ Adj
  - Die Lichter sind aufgehängt. -> die aufgehängt**en** Licher
  - Die Getränke sind kalt gestellt. -> die kalt gestellt**en** Getränke
  - Der Tisch ist gedeckt. -> der gedeckt**e** Tisch

## Zustandspassiv vs Aktiv

- Aktiv can't be converted to Vorgangspassiv

  - Die Sportstunde ist schnell beendet. (Zustandspassiv)→ Die Sportstunde wird schnell beendet.

  - Die Sportstunde ist schnell vergangen. (Aktiv)→ ~~Die Sportstunde wird schnell vergangen.~~

## Vorgangspassiv vs Zustandspassiv

- Vorgangspassiv: der **Prozess** ist wichtig
- Zustandspassiv: das Ergebnis ist wichtig
