# Phonetics: Accents

## Verben

| Condition                     | Choice        | Examples                                                     |
| ----------------------------- | ------------- | ------------------------------------------------------------ |
| viele Verben                  | Start of word | **ar**beiten, **le**sen, **schrei**ben, **hö**ren, **ler**nen, **spre**chen |
| Verben mit **be-** / **ent-** | After prefix  | be**die**nen, ent**wi**ckeln                                 |
| viele Verben mit **unter-**   | After prefix  | unter**rich**ten, unter**su**chen                            |
| Verben auf **-ieren**         | On **-ie-**   | konstru**ie**ren, stud**ie**ren, formul**ie**ren             |

## Nomen

| Condition                                      | Choice                     | Examples                                                     |
| ---------------------------------------------- | -------------------------- | ------------------------------------------------------------ |
| viele Nomen                                    | start                      | der **Na**me, die **Zei**tung, die **Fla**sche, die **Sei**te, die **Bri**lle, der **Schlü**ssel, die **Lam**pe, der **Kell**ner, die **Leh**rerin, der **Künst**ler |
| Komposita                                      | the same as the first word | der **Fuß**ball, das **Lehr**buch, der **Bild**schirm, der **Schreib**tisch, der O**ran**gensaft (= die O**ran**gen) |
| <ruby>Fremdwörter<rt>foreign words</rt></ruby> | often on the last syllable | der Student, der Patient, das Medikament, der Assistent, der Ingenieur, die Präsentiation, das Büro |
